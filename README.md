## What it does

`main.py` writes a single pickup line — spoken by a vending machine to a
passing human — to `/output/entry.txt`. One line, 122 characters, no
trailing newline.

> I've vended snacks to a thousand strangers, but you're the first I'd jam
> my own coil for — go on, press B4, I'm all yours.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
